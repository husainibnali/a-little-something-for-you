# A little something for you 💌

A responsive romantic date invitation.

## Publish

1. Upload `og-preview.png` at the repository root.
2. In Settings → Pages, select Deploy from a branch, main, /(root), and Save.
3. Visit https://husainibnali.github.io/a-little-something-for-you/

The WhatsApp RSVP message opens a chat with the sender without sending automatically.
